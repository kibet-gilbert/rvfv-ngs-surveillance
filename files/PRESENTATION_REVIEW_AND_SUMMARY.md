- Ask: "Where would a new unknown sequence cluster?"

- Ask: "Can you identify which samples belong to which lineage?"
- Learning goal: Understand how to read phylogenetic trees

## COMMON STUDENT QUESTIONS (ANTICIPATED)

**Q: "Can we use amplicon PCR for samples from 6 months ago?"**
A: RNA will be degraded. Frozen samples (at -80°C) can last 1-2 years. Room temperature samples: weeks at best. Always prioritize fresh samples.

**Q: "What if outbreak virus has new mutations at primer binding sites?"**
A: Real concern. Solution: Validate primer binding computationally against all known variants. Primal Scheme does this. If 5% of circulating viruses don't amplify well, that's acceptable (get 95% of cases).

**Q: "Can hospitals without advanced equipment participate?"**
A: Yes! RNA extraction (very basic equipment required). PCR machines standard in any microbiology lab. Library prep and sequencing can be outsourced to reference lab.

**Q: "How do we ensure data quality in resource-limited settings?"**
A: Use checklists (provided in quick reference guide). Implement QC gates: Don't report result unless coverage >80%. Send controls regularly to reference lab for validation.

**Q: "Will genomics replace serology/PCR diagnostics?"**
A: No! Diagnostics answer "Is this patient infected?" Genomics answers "What lineage? Where did it come from?" Complementary, not competitive.
